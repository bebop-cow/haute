# Haute — a free sewing school

**Play it:** https://bebop-cow.github.io/haute/

A hands-on browser game that teaches you to sew real clothes — no classes, no sewing machine, no expensive fabric needed.

- **The basics:** thread a needle, tie a knot, running stitch, backstitch, take your measurements.
- **Six projects**, each drafted from *your* measurements: shift dress, gathered sundress, fitted dress with darts, button-up shirt, jeans, and a suit.
- Every project ends with a **printable pattern card**: the exact points to draw the pattern on newspaper, plus the order of work.

Everything can be sewn by hand. Old bedsheets make great practice fabric.

It's a single `index.html` file with no build step. It works on phones and desktops, and your progress is saved in your browser.
